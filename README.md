# Spring Boot Application
# Using spring-boot-starter-thymeleaf Starter Kit for User Interface Development

# api-payload-downloader-ui
UI Component for the API Payload Downloader App

# Steps to Run the WEB UI Application :
    1. Navigate & Run the ApiPayloadDownloadUtilityUiApplication File as Spring Boot Application,
    2. Application will start on port 8080 (http) with context path '/'
    3. URL to Access the WEB UI Application : http://localhost:8080/
